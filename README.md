# Lungani Mncwango | Cloud & Infrastructure Portfolio

Personal portfolio website for Lungani Mncwango, highlighting cloud engineering, infrastructure, automation, cybersecurity, projects, and professional experience.

## View the site

[lungani-mncwango.github.io/lungani-portfolio-](https://lungani-mncwango.github.io/lungani-portfolio-/)

## Run locally

Open the portfolio file at `file:///C:/lungani-portfolio/index.html.html` in a modern web browser. No build tools or dependencies are required.

## Attach

- `index.html.html` — Portfolio website (current local filename)
- `assets/profile.png` — Hero-section profile photograph
- `Lungani-Mncwango-CV.docx` — Downloadable CV

## Deployment

The site is designed for GitHub Pages. Before publishing, rename `index.html.html` to `index.html`, then commit and push it to the repository root. Keep the profile image at `assets/profile.png`.
